# 审批意见书模板（§5.3 三段式，驳回/附条件强制输出）

> 渲染规则：`{...}` 占位一律填引擎 JSON 原始输出，禁止心算改数；测算数字用「约/大约/估算」措辞。

```
【规则引擎意见】{decision.result}：{描述}（{planned?计划内:非计划内}·{场景补充语}）
· 契约对照：corpus ¥{inputs.corpus} 扣 ¥{inputs.amount} 后余 ¥{inputs.remaining_after}，
  安全垫 ¥{inputs.effective_cushion}（{safety_cushion.mode} 模式）→ {是否击穿结论}
· 目标影响：{最相关目标} 达成延后 ≈ {impact.delay_months_simple} 个月（简化口径，
  误差 ±20%~50%；真实口径约 {F7.real_delay_months} 个月，含通胀/回撤，见公式 F7）
· 替代方案（优先级从高到低）：
  1. 从月度「合理享受」额度拆分支取（不破垫、不损目标）
  2. 拆分 {N} 个月分期支取（每月约 ¥{amount/N}，不击穿安全垫）
  3. 等待目标超额里程碑（≥120%）解锁奖励额度后支取
· {cooldown.triggered?「你可在冷静期 {cooldown.days} 天内撤回或申诉，规则引擎按纪律义务终裁」:「」}
```

## 场景措辞基调

- **A 批准**：简短放行 +「合理享受额度正常使用」，不说教；
- **B 附条件**：给出分期/延迟/缩减三选项之一的具体数字；
- **C 驳回**：必须附全部三段 + 替代方案，基调「不是不让你花，是帮你算清代价后选更好的花法」。

```

按当前攒钱节奏（月度可投增量约 ¥{inputs.monthly_invest_nominal}），
{目标名} 进度提前约 {F5提前月数} 个月。规则引擎替未来的你谢谢你。
```
